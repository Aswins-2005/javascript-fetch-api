# JavaScript Fetch API

A simple JavaScript project that demonstrates how to fetch user data from an API using two different approaches:

* Promise chaining with `.then()` and `.catch()`
* `async/await` with `try/catch`

## 🚀 API Used

[JSONPlaceholder](https://jsonplaceholder.typicode.com/users)

## 📌 Concepts Covered

* `fetch()`
* Promises
* `.then()`
* `.catch()`
* `async`
* `await`
* `try...catch`
* `response.json()`
* API requests and JSON data

## 🛠️ Technologies

* JavaScript
* REST API
* JSON

## ▶️ How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Open the HTML file in a browser.
4. Open the browser Developer Console using `F12`.
5. The fetched user data will be displayed in the console.
